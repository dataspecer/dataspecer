# Book Library actions

These actions are deliberately small examples of the three supported placements:

- a button in the Books list header,
- an icon button in every Books list row,
- a button on the Book detail page.

They only write their available entity data to the browser console.

After generating the Book Library application, copy the files to:

```text
books-list-actions.tsx    -> src/modules/book-list-row/
books-detail-actions.tsx  -> src/modules/book/
```
